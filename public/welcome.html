Welcome

Agent Board is a local tabbed viewer for pages the Cursor agent presents. Keep this window open. New pages show up as tabs.

Shortcuts

KeyAction
Ctrl+DSearch open and archived pages
Ctrl+SDownload the current page as HTML
Ctrl+HOpen this help page
Ctrl+ZRestore the last archived tab, or the last permanently deleted open tab (up to 5), whichever is newer
EscClose the archive sidebar
/ or Ctrl+FFocus archive search when the sidebar is open (Shift+7 on Nordic layouts)

Tabs

  • Middle-click a tab to archive it. Pinned tabs ignore middle-click; use ×. Shift+click × (or Shift+middle-click) permanently deletes after a confirmation.
  • Double-click a tab to pin or unpin it. Clear archives unpinned tabs and leaves pinned tabs alone.
  • The archive sidebar (button to the right of Clear) lists archived tabs. Click a row to restore it. Close a row to delete it permanently.
  • If tabs overflow, scroll the strip with the mouse wheel.

Persistence

Open tabs, the archive (up to 200), and the last 5 permanently deleted open tabs are saved to %LOCALAPPDATA%\agent-board\state.json, so they survive Cursor and Agent Board restarts. Override the folder with the AGENT_BOARD_HOME environment variable if needed.
