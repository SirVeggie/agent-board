Welcome

Agent Board is a local tabbed viewer for pages the Cursor agent presents. Keep this window open. New pages show up as tabs.

Shortcuts

KeyAction
Ctrl+DSearch open and archived pages
Ctrl+SDownload the current page as HTML (markup only; no data or images)
Ctrl+HOpen this help page
Ctrl+ZRestore the last archived tab, or the last permanently deleted open tab (up to 5), whichever is newer
EscClose the search palette, or the archive sidebar
/ or Ctrl+FFocus archive search when the sidebar is open (Shift+7 on Nordic layouts)

Search

  • Ctrl+D opens a palette over the board. Type to search titles, page content, and saved form data across open and archived tabs.
  • With an empty query it lists open tabs, then recent archived ones. ↑ ↓ move, Enter opens (restores an archived tab and switches to it), Esc closes.

Tabs

  • Middle-click a tab to archive it. Pinned tabs ignore middle-click; use ×. Shift+click × (or Shift+middle-click) permanently deletes after a confirmation. Ctrl+Z can restore that deletion if the tab was still open (last 5).
  • This Welcome page is part of the app. Closing it dismisses it instead of archiving; Ctrl+H opens it again.
  • Double-click a tab to pin or unpin it. Pinned tabs stay on the left. Clear archives unpinned tabs and leaves pinned tabs alone.
  • With Tab reordering on in Settings (logo), drag a tab to move it inside the pinned or unpinned group. Drop does not switch the page. Escape cancels.
  • Right-click a tab or an archived row to export that page with its data and images.
  • A dot on a tab means it was updated while you were looking at another tab.
  • If tabs overflow, scroll the strip with the mouse wheel. Settings (logo) has a toggle for smooth scrolling.

Archive and templates

  • The archive button to the right of Clear opens the sidebar. It has two tabs: Archive and Templates. A badge on that button means archived pages were updated, not the total count.
  • Click an archived row to restore it and switch to it. The search box matches titles, page content, and saved form data.
  • Close a row (× or middle-click) to delete it permanently after a confirmation. That cannot be undone. Empty deletes the whole archive.
  • Templates are reusable pages the agent creates when you ask. Click one to fill its form and Open a pinned copy. While that copy is selected, Edit on the right of the tab strip changes that page’s values.
  • Improving a template updates every page created from it. If the new version cannot use the old page data, the page is blocked until the agent fixes the data.
  • Drag the left edge of the sidebar to resize it. Esc clears the search box first, then closes the sidebar.

Import and export

  • Ctrl+S still saves the current page as a plain HTML file. Interactive data and attached images are not included, so that file is a snapshot of the markup, not a working board page.
  • Settings (logo) has Import, Export, and Export all. Export is a .board.json pack: HTML, title, pin, archive flag, JSON state, and images. Export all is the same format with every user page (open and archived). The Welcome page is skipped.
  • Import accepts a saved HTML file, a single-page export, or an export-all file. It detects the type from the contents. Existing pages are not overwritten; a colliding key gets a suffix.
  • Drop a file on the settings overlay (anywhere while Settings is open), on the tab strip, or on the archive sidebar. Settings and the tab strip restore archive status from the file (default open). The archive sidebar imports everything as archived.

Persistence

Open tabs, the archive, each tab's page state, and the last 5 permanently deleted open tabs are saved to %LOCALAPPDATA%\agent-board\board.sqlite, so they survive Cursor and Agent Board restarts. The archive is not capped; it stays until you empty it or delete rows. Override the folder with the AGENT_BOARD_HOME environment variable if needed.
