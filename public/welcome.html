Welcome

Agent Board is a local tabbed viewer for pages the Cursor agent presents. Keep this window open. New pages show up as tabs.

Shortcuts

KeyAction
Ctrl+DSearch every page in the Library
Ctrl+SDownload the current page as HTML (markup only; no data or images)
Ctrl+HOpen this help page
Ctrl+ZReopen the last closed tab, or undo the last delete (up to 10), whichever is newer
EscClose the search palette, or the Library sidebar
/ or Ctrl+FFocus Library search when the sidebar is open (Shift+7 on Nordic layouts)

Search

  • Ctrl+D opens a palette over the board. Type to search titles, page content, and saved form data across every page in the Library.
  • With an empty query it lists open tabs, then recently closed pages. ↑ ↓ move, Enter opens the page (as a tab if it was closed), Esc closes.

Tabs

  • Closing a tab (× or middle-click) keeps the page in the Library. Pinned tabs ignore middle-click; use ×. Shift+click × (or Shift+middle-click) deletes the page; the notice that appears has Undo, and Ctrl+Z works too (last 10 deletes).
  • This Welcome page is part of the app. Closing it dismisses it; Ctrl+H opens it again.
  • Right-click a tab to pin or unpin it. Pinned tabs stay on the left. Clear closes unpinned tabs and leaves pinned tabs alone.
  • Hover a tab for its full title, id, created and updated times, and Library folder.
  • Double-click a tab (or right-click → Copy ID) to copy a reference like Agent Board tab t_1a2b3c4d. Paste it into a chat so the agent knows exactly which page you mean.
  • With Tab reordering on in Settings (logo), drag a tab to move it inside the pinned or unpinned group. Drop does not switch the page. Escape cancels.
  • Right-click a tab or a Library row to export that page with its data and images.
  • A dot on a tab means it was updated while you were looking at another tab.
  • If tabs overflow, scroll the strip with the mouse wheel. Settings (logo) has a toggle for smooth scrolling.

Library and templates

  • The Library button to the right of Clear opens the sidebar. It has two tabs: Library and Templates. A badge on that button means closed pages were updated, not the total count.
  • The Library holds every page, open or closed. Open pages have an accent bar and a brighter title; the current tab's row is filled. Pinned pages have a faint warm tint.
  • Click a page to open it or switch to it; middle-click opens it in the background. Click a folder to expand or collapse it; right-click it to open or close all its pages, rename, move, export, or delete it.
  • Drag rows to reorder them or move them into folders (hover a collapsed folder to expand it). Drag a Library page onto the tab strip to open it at that spot, or drag a tab into the Library to file it and close the tab. While dragging a tab, hover the Library button to open the sidebar.
  • Double-click or F2 renames a page or folder. Agents keep their hands off a title you set for 24 hours. Alt+↑ ↓ nudges the focused row, Delete deletes it.
  • Deleting a folder offers to move its contents up or delete everything. A folder delete, or any bulk delete, is one undo step.
  • Templates are reusable pages the agent creates when you ask. Click one to fill its form and Open a pinned copy. While that copy is selected, Edit on the right of the tab strip changes that page’s values.
  • Improving a template updates every page created from it. If the new version cannot use the old page data, the page is blocked until the agent fixes the data.
  • Drag the left edge of the sidebar to resize it. Esc clears the search box first, then closes the sidebar.

Import and export

  • Ctrl+S still saves the current page as a plain HTML file. Interactive data and attached images are not included, so that file is a snapshot of the markup, not a working board page.
  • Settings (logo) has Import, Export, and Export all. Export is a .board.json pack: HTML, title, pin, open or closed, Library folder and position, JSON state, and images. A page made from a template also carries that template and its form values. Export all is the same format with every user page and every template; right-click a folder to export just that folder. The Welcome page is skipped.
  • Import accepts a saved HTML file, a single-page export, or an export-all file. It detects the type from the contents. Existing pages are not overwritten; a colliding key gets a suffix. Imported template pages stay linked to their template. If the board already has an identical template, it is reused; a template with the same name but different content is added as a separate template.
  • Drop a file on the settings overlay (anywhere while Settings is open), on the tab strip, or on the Library sidebar. Settings and the tab strip keep the open or closed status from the file (default open). The Library sidebar imports everything closed.

Persistence

The Library, its folders, open tabs, each page's state, and the last 10 deletes are saved to %LOCALAPPDATA%\agent-board\board.sqlite, so they survive Cursor and Agent Board restarts. The Library is not capped; pages stay until you delete them. Override the folder with the AGENT_BOARD_HOME environment variable if needed.
