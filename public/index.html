Waiting for a page

Ask the Cursor agent to present an investigation, analysis, or design here. New pages show up as tabs. Keep this window open.

  • Ctrl+Topens a new page to start from a template or with the agent
  • Ctrl+Dsearches every page, or threads with =
  • Ctrl+Sdownloads the current page as HTML (markup only)
  • Ctrl+Hopens the help page
  • Ctrl+Bshows or hides the Library sidebar
  • Ctrl+Eshows your spaces, each with its own tabs (Ctrl+Shift+PgUp/PgDn switches)
  • Ctrl+Zreopens the last closed tab or restores the last delete
  • Ctrl+Lopens the agent chat in the sidebar (Ctrl+Shift+L full window)
  • Ctrl+Kopens the floating agent chat over the page
  • Ctrl+.cycles the current chat's workspace, then none (Ctrl+Shift+. cycles Scribe access)
  • Ctrl+Shift+Mswitches between the normal and compact window
